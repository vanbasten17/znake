## Why

Znake already has solid loop fundamentals, but it still feels mostly systemic. We need one polished, identity-rich vertical slice to validate premium quality and sharpen product positioning.

## What Changes

- Introduce one cohesive biome slice ("Void Depths") with stronger visual identity.
- Add one biome-exclusive mechanic (moving void rift hazard).
- Add one biome-exclusive enemy variant (stalker).
- Add one biome-exclusive pickup item (core fragment).
- Add one mini-boss encounter on interval floors.

## Capabilities

### Modified Capabilities

- `gameplay`: biome-specific hazards, enemies, item, and boss encounter.
- `balance-config`: biome tuning values centralized for fast iteration.

## Impact

- Affected files:
  - `src/game/scenes/GameScene.ts`
  - `src/game/core/types.ts`
  - `src/game/core/balance.ts`
- No backend or platform changes.
