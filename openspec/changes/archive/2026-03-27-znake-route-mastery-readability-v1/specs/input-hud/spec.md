## ADDED Requirements

### Requirement: Route-mastery HUD readout readability

The system SHALL keep route-mastery HUD readout concise while preserving objective and route-preview readability.

#### Scenario: Route-mastery readout stays bounded in run HUD

- **WHEN** route mastery status is appended to run HUD route context
- **THEN** readout remains short and scannable on desktop and portrait mobile
- **AND** objective-critical labels remain readable
