## ADDED Requirements

### Requirement: Interactive Parallax Grid
The background MUST feature at least two layers of grid lines that move at different speeds (parallax) relative to the camera shake or snake movement.

#### Scenario: Ripple Propagation
- **WHEN** the snake eats food or hits a wall
- **THEN** a ripple effect (e.g., a momentary scale up of grid intersection points) MUST propagate across the grid.

### Requirement: Neon Nebula Corners
The background MUST replace static circles with soft, glowing "nebula" gradients in corners that pulse slowly to create atmosphere.

#### Scenario: Pulse Synch
- **WHEN** the "run status" UI text changes or events occur
- **THEN** the nebula gradient's intensity MUST pulse to reinforce the vibe.
