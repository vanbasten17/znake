## Design

### Scope (v1 scaffold)

- Keep current boss spawn trigger cadence.
- Add explicit boss-encounter loop expectations in spec before larger mechanics.
- Add lightweight boss support loop that keeps shield-powerup opportunities available.
- Stage implementation in small increments:
  1. shield-support availability
  2. phase/readability feedback
  3. objective state clarity
  4. post-boss transition pacing

### Guardrails

- No changes to non-boss objectives.
- No new persistent profile schema.
- Keep keyboard/touch/voice controls unaffected.

### Follow-up Applies

- Apply 1: visual/telemetry phase scaffolding.
- Apply 2: encounter mechanics increment (one new move pattern).
- Apply 3: balance tuning after smoke sessions.
